# Office Interio website

Public website for Office Interio, a brand of Omnaad Studio (Pune).

- `public/` is everything that gets published. `public/index.html` is the whole site for now: Projects (completed work) and Catalogue (office furniture).
- `public/projects/<name>.html` is one page per project (Alfa, Gamma, Marathon Futurex), opened in a new tab from the home page cards. The pages are generated by `tools/build_projects.py`: add a project's text and images there, run `python3 tools/build_projects.py`, and add a card to the `projects` list in `public/index.html`.
- Project images live in `public/images/projects/<name>/`, each as `<shot>.jpg` (2400px) and `<shot>-sm.jpg` (1000px), JPEG quality 82. Current images are real photographs; any render must be captioned "Design visual".
- `public/css/site.css` holds the shared brand styles; `public/css/project.css` adds the project-page layout.
- `public/products/<name>.html` is one detailed page per catalogue item (gallery, finishes, specs, size drawing, downloads, FAQ, related items), generated by `tools/build_products.py`. Values there are typical until a partner factory confirms them; add real product photos under `public/images/products/<name>/`.
- `public/images/` holds photos.
- Hosting: Cloudflare Workers static assets (free), set up in `wrangler.jsonc`. Every change to `main` deploys automatically to https://officeinterio.harshkahateprojects.workers.dev.

Content in [BRACKETS] or marked "Sample" / "Draft note" is placeholder and still needs real details.

## Brand rules (from the Office Interio brand book, 2026)

- Font: Jost only, 500 for headings, 400 for body.
- Colours: Paper #F5F5F3, Bone #E3DDD1, Ink #111111 carry the page. One Oak #9A7249 accent per layout. Tobacco #6B4F32 for small accent labels. No text in Travertine, no Paper on Oak.
- Square corners everywhere. Pills only for buttons. No drop shadows; lift cards with Bone.
- Voice: we and you, sentence case, short sentences, real numbers, no exclamation marks. Never: world-class, state-of-the-art, cutting-edge, one-stop solution, dream office, synergy.
- Photos: real, daylit, straight verticals, client-approved. Renders are labelled "Design visual".
- Logo files in `public/images/brand/` were cut from the brand book PDF. Replace with the original SVG files when available.

## Shared parts and extra pages

- `public/js/site.js` builds the footer and the floating enquiry button on every page. Contact details (phone, email, WhatsApp, address, social links, hours) live only in the `SITE` block at the top of that file. When a WhatsApp number is set, the floating button opens WhatsApp. Without one, it goes to the site visit form.
- `public/why.html` is the "Why Office Interio" page. `#brokers` is the section for brokers and building managers.
- `tools/links.py` records which catalogue pieces appear in which project (`USED`). Product pages show "Seen in our projects" and project pages show "Pieces in this project" from it. Rebuild both generators after editing it.
- `tools/build_catalogue.py` builds `public/downloads/office-interio-catalogue.pdf` from the product data (needs Playwright). Rebuild it after changing products, and change `SITE_URL` once the domain is live.
